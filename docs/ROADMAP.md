## 1. Поточний стан

- Astro (`output: 'server'`, `@astrojs/node` standalone) + Svelte 5, дані з TMDB через власні `/api/*` (ключ лише на сервері).
- Сторінки: `/` (каталог), `/details/[mediaType]/[id]`, `/person/[id]`, `/favorites`, `/offline` (пререндерена).
- Улюблені — `localStorage['movie-finder-favorites-v1']`, лише на цьому пристрої.
- Мова (uk/en) і тема (dark/light) — `localStorage['pet-locale-mode']`, `['pet-theme-mode']`.
- Перевірки: `npm run ci` (format, typecheck, 26 unit, 10 e2e з мокнутим API, build). **CI на GitHub і git remote ще немає.**

### Як працює PWA

| Що                        | Стратегія                                     |
| ------------------------- | --------------------------------------------- |
| JS/CSS/іконки, `/offline` | precache                                      |
| Сторінки (SSR)            | NetworkFirst (5 с), фолбек — `/offline`       |
| `/api/*`                  | NetworkFirst (8 с), до 200 відповідей на добу |
| Постери `image.tmdb.org`  | CacheFirst, до 400 шт. на 30 днів             |

Конфіг — `pwa.config.mjs`, реєстрація SW — `src/layouts/Layout.astro`.

## 2. Що вже зроблено (жовтень 2026)

**PWA (з нуля)**

- Manifest, service worker, PNG-іконки (`public/icons/`, генерація: `npm run icons`), iOS meta-теги, safe-area, офлайн-сторінка.

**Дизайн**

- Mobile-first: прибрано глобальні `:global(...) !important` перевизначення; теми через токени в `src/styles/global.css`, тема застосовується до першого рендеру (без блимання).
- Спільний `Layout.astro`, липка шапка (мова/тема), нижня навігація «Пошук / Улюблені».
- Каталог: пошук вгорі, категорії й добірки — чипи з горизонтальним скролом, фільтри — bottom sheet з лічильником активних, скелетони, компактна пагінація, кнопка «вгору».
- Картка фільму: компактна горизонтальна (постер 96px), ♡ для швидкого додавання.
- Деталі: backdrop-шапка, жанри, улюблені за категоріями, трейлер вантажиться лише після тапу, актори в горизонтальному скролі, «Поділитися».
- Актор: профіль, згортання довгої біографії, сітка фільмографії.
- Перемикач мови працює на всіх сторінках і в API (деталі, актор).

**Виправлені баги**

- Фільтр країни «RU» за підрядком назви відкидав також Перу й Бруней → тепер точні ISO-коди.
- Сортування «Найстаріші» в режимі «Усе» сортувало від найновіших.
- Віковий рейтинг для всіх фільмів був «13+» → справжні сертифікації TMDB (UA → US → GB → DE).
- `favorites.ts` мутував спільний порожній об’єкт; захист від зіпсованого `localStorage`.
- Гонка запитів у каталозі: застаріла відповідь могла перезаписати нову.

**Тести**

- Unit: улюблені, пагінація, фільтри/сортування discover, віковий рейтинг, i18n, PWA-конфіг.
- E2E (Pixel 7, API мокнуто): пошук, категорії, фільтри, пагінація, улюблені, деталі → актор, мова й тема, помилка API.

## 3. Чекліст до робочого використання

### 3.1 Обов’язково перед релізом

- [ ] Створити репозиторій на GitHub, `git remote add origin …`, закомітити й запушити.
- [ ] Додати CI (GitHub Actions: `npm ci`, `npx playwright install --with-deps chromium`, `npm run ci`) і, за бажанням, `pre-push` хук, як у cards.
- [ ] **Хостинг з Node і HTTPS** (без HTTPS PWA не встановиться): Render / Railway / Fly.io / VPS. Або змінити адаптер (Vercel, Netlify, Cloudflare).
- [ ] **Ключ TMDB на сервері.** Перевірити, чи Astro вбудовує `TMDB_API_KEY` у збірку під час `build`, чи читає зі змінних середовища під час роботи. Надійніше перейти на `astro:env` (`envField.string({ context: 'server', access: 'secret' })`), щоб ключ задавався на хостингу й не потрапляв в артефакт збірки.
- [ ] **Атрибуція TMDB** — вимога умов використання API: логотип TMDB і текст «This product uses the TMDB API but is not endorsed or certified by TMDB» (наприклад, сторінка «Про застосунок» або футер).
- [ ] **Захист `/api/*`**: зараз будь-хто може викликати ці роути й витрачати ліміт ключа. Rate limit за IP і серверний кеш відповідей.
- [ ] Ручна перевірка на реальних iPhone і Android: встановлення, запуск з іконки, офлайн (відкрита раніше сторінка, улюблені, `/offline` для нової сторінки), оновлення версії.
- [ ] Видалити невикористане або підключити: `/api/collections.json`, `/api/collection/[id].json`, `/api/person/popular.json` (UI їх не викликає), `public/logo.svg`, `public/favicon.ico`.
- [ ] `npm audit` — під час встановлення були попередження, переглянути.

### 3.2 Продуктивність і трафік (важливо для мобільного інтернету)

- [ ] **N+1 запити**: `/api/discover.json` на кожну сторінку робить 1 + до 20 запитів деталей у TMDB (у режимі «Усе» — удвічі більше). Кешувати деталі на сервері (in-memory LRU/Redis на години) або брати жанри з `genre_ids` без окремого запиту.
- [ ] **Розміри постерів**: `makeImageUrl` за замовчуванням `w500`, а в списку постер 96px. Використовувати `w185`/`w342` + `srcset`.
- [ ] `Cache-Control` для HTML-сторінок і статики на рівні сервера/CDN.

### 3.3 Дані та надійність

- [ ] Улюблені лише в `localStorage` — легко втратити (очищення даних, видалення PWA на iOS). Мінімум — експорт/імпорт JSON; краще — акаунт і синхронізація (можна з Firebase, як у cards).
- [ ] `navigator.storage.persist()` при першому додаванні в улюблені (як у cards).
- [ ] Моніторинг помилок (Sentry або аналог) для клієнта й API.
- [ ] Серверні тексти в API не локалізовані для англійської: «Невідомо», «Опис поки відсутній.», «Біографія поки відсутня.», «Без назви», стать.
- [ ] Заголовки безпеки (CSP з дозволом на `image.tmdb.org`, `i.ytimg.com`, `youtube-nocookie.com`).

## 4. Покращення функціональності

1. **Де подивитися** — TMDB watch providers для UA (Netflix, MEGOGO, Sweet.tv…). Найкорисніше для вибору ввечері.
2. **Нескінченна прокрутка** на телефоні замість пагінації.
3. **Підказки під час пошуку** з затримкою (`/search/multi`), включно з акторами.
4. **Улюблені**: позначка «переглянуто», власна оцінка/нотатка, сортування, перейменування й переміщення між категоріями. Зараз порожня категорія видаляється, щойно з неї прибрано останній фільм; «Загальне» показується завжди.
5. Схожі фільми та рекомендації на сторінці деталей.
6. Для серіалів — сезони й епізоди, статус (виходить / завершено).
7. Фільтр вікового рейтингу зараз лише за US-сертифікацією фільмів — врахувати серіали й UA.
8. README каже «до вибору категорії запитів немає», а зараз каталог одразу вантажить «Усе» (популярне за 120 днів). Вирішити, що правильно, й оновити опис.

## 7. Ухвалені рішення

| Рішення                                                         | Чому                                                                           |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| SSR + власні `/api/*`                                           | Ключ TMDB не потрапляє в браузер                                               |
| У SW немає `navigateFallback`, лише NetworkFirst + `/offline`   | SSR-сторінок немає в precache; універсальний фолбек ховав би справжні сторінки |
| Двомовний інтерфейс (uk/en), за замовчуванням uk                | Так було задумано в проєкті; переклади — через `tr()` у `src/lib/i18n.ts`      |
| Каталог за замовчуванням — «популярне за 120 днів»              | «Найновіші» показували нові релізи без рейтингу й перекладу                    |
| RU завжди виключається з результатів (за ISO-кодом країни)      | Вимога проєкту; тепер без хибних збігів                                        |
| Трейлер — заставка, iframe лише після тапу (`youtube-nocookie`) | Економія трафіку на телефоні, менше трекінгу                                   |
