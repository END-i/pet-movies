# Movie Finder (Astro + Svelte)

Проєкт пошуку фільмів, мультфільмів і TV-шоу на базі Astro + Svelte, без UI бібліотек.

## Що реалізовано

- Каталог: одразу показує «Усе» (популярне за останні 120 днів); категорії, добірки, фільтри (жанр, рейтинг, голоси, рік, країна, вік глядача), приховані жанри, пошук за назвою з підказками під час введення й рядом «Люди».
- Картка: постер, назва, рік, країни, жанри, опис, статус («Онлайн» / «У кіно» / «Анонс», для серіалів — статус і сезони), позначка «немає перекладу» обраною мовою, ♡.
- Деталі: інформація, де подивитися в Україні, трейлер, актори, сезони, рекомендовані й схожі за темою, категорії улюблених.
- Людина: біографія, фільмографія з ролями й сортуванням.
- Улюблені: категорії, резервна копія у файл, зберігання в `localStorage`.
- Мови інтерфейсу: українська, англійська, болгарська, німецька, іспанська, французька (`src/lib/i18n.ts`, `src/lib/locales/`).

## Сторінки

- `/` — пошук і список контенту
- `/details/[mediaType]/[id]` — деталі
- `/person/[id]` — людина
- `/favorites` — улюблені
- `/offline` — сторінка без мережі (PWA)

## Налаштування

1. Створіть `.env` у корені проєкту.
2. Додайте ключ TMDB:

```env
TMDB_API_KEY=your_tmdb_key
```

Отримати ключ можна в акаунті [TMDB](https://www.themoviedb.org/).

## PWA

- Manifest + service worker (`@vite-pwa/astro`, конфіг у `pwa.config.mjs`).
- Сторінки й `/api/*` кешуються за стратегією network-first, постери TMDB — cache-first.
- Без мережі показується пререндерена сторінка `/offline`; улюблені працюють офлайн (`localStorage`).
- Іконки: `public/icons/icon.svg` → PNG через `npm run icons`.
- Встановлення на телефон потребує HTTPS (сервер Node, `output: 'server'`).

## Команди

```bash
npm install
npm run dev
```

- `npm run test` — unit-тести (Vitest).
- `npm run test:e2e` — e2e на мобільному профілі (Playwright). API мокається, ключ TMDB не потрібен.
- `npm run typecheck` — `astro check`.
- `npm run ci` — format + typecheck + unit + e2e + build.

Для production-збірки:

```bash
npm run build
TMDB_API_KEY=... HOST=0.0.0.0 PORT=4321 node dist/server/entry.mjs
```

Ключ TMDB читається зі змінної середовища під час роботи сервера (`astro:env`, secret) і не потрапляє в `dist/`. Локально його бере з `.env`.

## Деплой на Vercel (безкоштовно)

Адаптер обирається автоматично: під час збірки на Vercel (змінна `VERCEL=1`) — `@astrojs/vercel`, в інших випадках — `@astrojs/node`.

1. [vercel.com](https://vercel.com) → увійти через GitHub → **Add New → Project** → імпортувати `END-i/pet-movies`.
2. Framework Preset — Astro (визначиться сам), інші налаштування не змінювати.
3. **Environment Variables**: `TMDB_API_KEY` = ваш ключ (Production і Preview).
4. **Deploy**. Далі кожен push у `main` деплоїться автоматично, а гілки отримують превʼю-адреси.
5. Відкрити адресу `*.vercel.app` на телефоні → «Встановити застосунок» / «На екран „Додому“».

Кеш TMDB і rate limit зберігаються в пам’яті функції, тому на Vercel вони діють у межах одного «теплого» інстансу. Для кількох користувачів цього достатньо.
